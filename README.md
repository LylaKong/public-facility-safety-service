# 우리동네 공공시설물 안전정보 서비스 (My Neighborhood Public Facility Safety Info)

국토안전관리원 시설물 통계 정보조회 서비스 API 및 공공시설물 위치 데이터를 연계하여, 지역별(시·도) 공공인프라 현황과 시설물 정보를 지도 및 목록으로 직관적으로 탐색할 수 있는 반응형 웹 서비스입니다.

---

## 1. 주요 특징 및 PRD 요구사항 구현 내용

### 1) 지역 및 부문별 통계 시각화 (PRD Step 1)
- **17개 시·도별 통계 조회:** 서울, 경기, 부산 등 전국 17개 광역시·도의 등록 시설물 총량 및 유형별(교량, 터널, 하천, 댐, 항만, 옹벽 등 10종) 통계 제공
- **공공 vs 민간 부문 통계:** 국토안전관리원 1종·2종·3종 시설물 안전관리 등급별 세부 분포 카드 제공
- **데이터 출처 및 메타데이터:** 원본 데이터 갱신일, 조회 시각(fetchedAt), 데이터 소스 명확 표기

### 2) Leaflet 지도 및 시설물 목록 양방향 연동 (PRD Step 2 & Step 3)
- **지도 마커 ↔ 목록 연동:**
  - 목록에서 시설물 클릭 시 지도 중심이 해당 시설물로 부드럽게 이동(`flyTo`)하고 팝업이 자동 활성화됩니다.
  - 지도 마커 클릭 시 해당 시설물 카드가 강조(Highlight)되고 상세 정보 패널과 동기화됩니다.
- **지역 선택 자동 포커싱:** 시·도 변경 시 해당 행정구역 중심 좌표로 지도 뷰 자동 이동
- **좌표 미제공 시설물 예외 처리:** 정확한 좌표가 없는 데이터는 임의 위치에 마커를 찍지 않고, 목록 내 '위치 미제공' 뱃지로 투명하게 안내
- **내 위치 탐색:** GPS 기반 내 주변 시설물 이동 및 권한 거부 시 안내 피드백 제공

### 3) 엄격한 정보 신뢰성 및 안전정보 표현 준수 (PRD 1.4 & 5.4)
- **임의의 안전등급/위험도 생성 금지:** 공공데이터에서 제공하지 않는 "안전한 시설물", "위험 등급", "실시간 안전점수" 등의 임의 추정 데이터를 철저히 배제
- **안전 정책 안내 배너:** 공공데이터 기준 및 객관적 사실 중심의 운영 원칙을 상단 배너와 상세 모달에 고지

### 4) 철저한 API 보안 및 프록시 아키텍처 (PRD 5.1 & 5.2)
- **서버 측 API 키 은닉:** 공공데이터포털 인증키(`FACIL_STAT_SERVICE_KEY`)를 Express 백엔드 환경변수(`.env`)에서만 처리하여 브라우저에 인증키가 노출되지 않음
- **안정적인 캐싱 및 Fallback:** 인메모리 TTL 캐싱(10분)으로 일일 호출 한도(10,000회)를 보호하며, API 키 미등록 또는 점검 시에도 기준 통계 모드로 무중단 서빙

### 5) 반응형 모바일/데스크톱 최적화 (PRD 3.3)
- **데스크톱:** 좌측 60% Leaflet 지도 + 우측 40% 시설물 목록 스크롤 뷰 동시 제공
- **모바일/태블릿:** 상단 `[지도 보기]` / `[목록 보기]` 원클릭 탭 전환 UI 적용

## 3. 실행 방법

### 1) 환경변수 설정 (선택사항)
공공데이터포털에서 발급받은 국토안전관리원 인증키가 있을 경우 루트의 `.env` 파일에 입력합니다:
```env
PORT=5000
FACIL_STAT_SERVICE_KEY=발급받은_인증키
```
> ※ 키를 입력하지 않아도 사전 구축된 17개 시도 기준 통계 및 검증 시설물 데이터셋으로 즉시 모든 기능을 체험할 수 있습니다.

### 2) 개발 모드 실행 (서버 + 클라이언트 동시 실행)
```bash
npm run dev
```
- 백엔드 프록시: `http://localhost:5000`
- 프론트엔드 Vite 개발 서버: `http://localhost:3000`

### 3) 프로덕션 빌드 및 실행
```bash
# 클라이언트 빌드
npm run build

# 통합 서버 실행 (단일 포트 5000에서 API + 웹 서비스 제공)
npm start
```
웹 브라우저에서 `http://localhost:5000`으로 접속하여 서비스를 이용할 수 있습니다.
